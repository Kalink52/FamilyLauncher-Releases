# Family Launcher Releases

Official Windows downloads and signed update metadata for Family Launcher.

## Download

Download the setup `.exe` from the [latest release](https://github.com/Kalink52/FamilyLauncher-Releases/releases/latest). Downloads will become available after the first release is published.

## Updates

Updater-enabled versions check this repository on startup and offer **Update & Restart** when a newer version is available. Older versions need one manual installation of an updater-enabled release.

This repository hosts release files and update metadata. Application source code and private signing keys are maintained separately.
